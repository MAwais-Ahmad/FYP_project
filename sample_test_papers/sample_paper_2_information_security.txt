1. [2 Marks | Time: 120s] Which property of the CIA triad ensures that data has not been modified or tampered with by unauthorized parties?
A) Confidentiality
B) Integrity
C) Availability
D) Non-Repudiation
Correct Answer: B
Explanation: Integrity guarantees that information is authentic, complete, and protected against unauthorized modification.

2. [2 Marks | Time: 120s] Symmetric encryption algorithms use:
A) Two mathematically related keys (public and private).
B) A single shared secret key for both encryption and decryption.
C) Hashing functions without any keys.
D) Digital certificates verified by a Root Authority.
Correct Answer: B
Explanation: Symmetric key cryptography relies on a single shared key between communicating parties.

3. [2 Marks | Time: 120s] In Role-Based Access Control (RBAC), access permissions are assigned directly to:
A) Individual user identity credentials only.
B) Roles based on organizational duties, which are then assigned to users.
C) Object security labels based on sensitivity clearance levels.
D) Network IP addresses and subnet masks.
Correct Answer: B
Explanation: RBAC maps permissions to roles, and users acquire permissions by being assigned to appropriate roles.

4. [2 Marks | Time: 120s] Multi-Factor Authentication (MFA) requires combining factors from at least two different categories. Which pair represents true MFA?
A) Password and PIN number.
B) Password and Security Question answer.
C) Password (something you know) and Authenticator App OTP (something you have).
D) Fingerprint scan and Facial recognition scan.
Correct Answer: C
Explanation: Password (knowledge) + App OTP (possession) combines two distinct authentication factors.

5. [2 Marks | Time: 120s] What type of attack attempts every possible combination of characters until the correct password is found?
A) Man-in-the-Middle Attack
B) Phishing Attack
C) Brute Force Attack
D) SQL Injection Attack
Correct Answer: C
Explanation: Brute force systematically checks all probable key or password combinations until finding a match.

PART 2: SHORT TECHNICAL QUESTIONS (10 Marks)
Time Limit: 15 Minutes
================================================================================

6. [5 Marks | Time: 450s]
Question: Explain the difference between Symmetric Cryptography (e.g., AES) and Asymmetric Cryptography (e.g., RSA) in terms of key management, execution speed, and common use cases.
Key Points:
- Symmetric uses 1 secret key for encryption & decryption; Asymmetric uses a public/private key pair.
- Symmetric is computationally fast and suitable for bulk data transfer; Asymmetric is slower due to heavy math operations.
- Asymmetric solves the key distribution problem and is used for key exchange, digital signatures, and SSL/TLS handshakes.

7. [5 Marks | Time: 450s]
Question: Define SQL Injection (SQLi) vulnerability. Explain how parameterized queries (prepared statements) prevent SQLi attacks.
Key Points:
- SQL Injection occurs when untrusted user input is concatenated directly into executable database query strings.
- Attackers exploit SQLi to bypass authentication, extract sensitive data, or modify database contents.
- Parameterized queries separate query logic from data parameters, treating user input strictly as literals rather than executable SQL code.

PART 3: SECURITY SCENARIO ANALYSIS (10 Marks)
Time Limit: 20 Minutes

8. [10 Marks | Time: 1200s]
Question: A financial tech company is designing a secure remote login system for enterprise online banking. Outline a comprehensive zero-trust security architecture for this portal. Address authentication mechanisms, session management, access control model, network encryption, and audit logging to defend against credential stuffing and session hijacking.
Key Points:
- Zero-Trust Principle: Enforce explicit verification ("never trust, always verify") regardless of internal or external network location.
- Multi-Factor Authentication: Mandatory FIDO2 WebAuthn / TOTP hardware token to eliminate password-only vulnerabilities.
- Session Management: Cryptographically secure HTTP-only, Secure, SameSite cookies with short expiration timeouts and TLS binding.
- Access Control: Fine-grained Role-Based Access Control (RBAC) combined with Attribute-Based Access Control (ABAC) for dynamic risk scoring.
- Encryption & Audit Logging: TLS 1.3 in transit with AES-256 for data at rest, accompanied by immutable, centralized SIEM event logging.
