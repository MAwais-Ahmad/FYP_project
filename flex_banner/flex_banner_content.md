## 📖 Main Body Content (White Background, Maroon Card Borders)

### 1. Abstract
**AI Teacher Assistant (AITA)** is **primarily** an intelligent diagnostic system engineered for **Cognitive Learning Style Categorization**. By capturing real-time behavioral analytics during student test interactions, AITA automatically classifies learners into 8 operational cognitive profiles. **Secondarily**, it functions as a **Multimodal Assessment Platform**—offering AI Adaptive Scenarios, Custom PDF/PPTX Paper OCR, and AI Material Exams—to collect interaction data, empower teachers with diagnostic class intelligence, and deliver personalized AI coaching.

### 2. Problem Statement & Objectives (Grid Layout)
- **Problem Statement:** Traditional assessment software treats testing as a black box—outputting shallow right-or-wrong (pass/fail) scores while ignoring *how students reach such results*. **AITA** bridges this critical gap by capturing real-time behavioral analytics (pacing, answer revisions, item variance, reflection depth) to diagnose operational **Cognitive Learning Styles**, providing teachers with diagnostic intelligence rather than just a numeric grade.
- **Objectives:**
  - **Process-Based Diagnosis:** Shift evaluation from static marks to real-time analytics.
  - **Automated Categorization:** Classify 8 learner profiles with confidence scoring.
  - **Multimodal Evaluation:** Support AI scenarios, PDF/PPTX OCR, & Bloom's exams.
  - **Class Intelligence:** Empower teachers with cognitive analytics & AI lookup.

### 3. Technology Used
React 18 • TypeScript • TailwindCSS • Node.js • Express • Prisma ORM • PostgreSQL • Random Forest (ML) • OpenAI GPT-4o • Llama 3.3 70B • officeparser • pdf-parse

### 4. Core Features
1. **1. REAL-TIME TEST TELEMETRY:** Captures multi-dimensional student interaction telemetry during testing—including response pacing, answer revisions under time pressure, language depth, and metacognitive reflection.
2. **2. AUTOMATED ML PROFILING:** Feeds interaction telemetry into a trained Random Forest classifier with confidence scoring to automatically derive and map patterns into 8 operational cognitive learning profiles.
3. **3. MULTIMODAL ASSESSMENTS:** Goes beyond static question banks by offering dynamic AI adaptive scenarios and custom PDF/PPTX paper OCR to evaluate real-world reasoning across Bloom's Taxonomy.

### 5. Methodology & Acknowledgements (Grid Layout)
- **Methodology Flow:** User Auth & Session Join → Assessment Mode Selection → Real-Time Interaction Metrics → Cognitive Profiling Engine → AI Advisor & Class Intelligence
